# W-9 Request Letter

> **Template — not legal advice/not tax advice.** See `legal/README.md`.
> Send this to any contractor before their first payment. If total
> payments to them in a calendar year reach the IRS's 1099-NEC
> threshold, you'll need the info this collects to file it correctly —
> confirm the current threshold and filing rules with a tax
> professional or IRS.gov, since these change.

---

Subject: W-9 needed before payment — Cooper River Trading Co.

Hi **[Contractor's name]**,

Before we send your first payment for **[brief description of the
work]**, we need a completed IRS Form W-9 on file. This is standard for
any independent contractor we pay, so we can report payments correctly
at tax time if required.

You can download the current W-9 form directly from the IRS:
https://www.irs.gov/forms-pubs/about-form-w-9

Please fill it out and send it back to **[your email/address]** by
**[date, if there's a deadline]**. If you have questions about how to
fill it out, the IRS's instructions are on the same page, or check with
your own tax preparer.

Thanks,
**[Your name]**
Cooper River Trading Co.
**[contact info]**

---

*Internal note: store the completed W-9 securely (it contains the
contractor's SSN/EIN) — never in plain text in Appraze, email
attachments left unencrypted, or anywhere unnecessary people can access
it. A locked file or a dedicated document-storage tool is standard
practice.*
