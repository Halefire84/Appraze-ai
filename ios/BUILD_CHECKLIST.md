# iOS Build Checklist

- [ ] Mac available with supported Xcode/iOS SDK
- [ ] Apple Developer membership active
- [ ] Bundle ID registered
- [ ] Signing team selected in Xcode
- [ ] Production HTTPS URL configured
- [ ] WKWebView shell created
- [ ] Debug simulator build succeeds
- [ ] Physical iPhone build succeeds
- [ ] Release archive succeeds
- [ ] Archive validation succeeds
- [ ] TestFlight upload succeeds
- [ ] TestFlight smoke test passes
- [ ] App Store Connect metadata complete
- [ ] Privacy declarations complete
- [ ] App Review submission prepared

No iOS build is claimed from the current non-macOS environment.
